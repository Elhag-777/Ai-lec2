مهم: ارفع الملفات المستخرجة وليس ملف ZIP.
1. لو المحاضرة في مستودع مستقل: ارفع index.html و AI-L02-Search-Introduction.pdf مباشرة في جذر المستودع.

3. من GitHub Settings > Pages اختر Deploy from a branch ثم main ثم /(root).
4. رابط المحاضرة في الحالة الثانية ينتهي بـ /lecture-02/
5. صور السلايدات مدمجة داخل index.html، أما ملف PDF الكامل فهو ملف مستقل بجانب الصفحة.
